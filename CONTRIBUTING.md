
# Guia de contribucion - Tienda TECSUP

Gracias por tu interes en colaborar con este proyecto.

Esta guia explica como reportar errores, proponer mejoras y enviar cambios mediante GitHub.

## Como reportar un error

1. Ingresa al repositorio en GitHub.
2. Abre la pestaña **Issues**.
3. Haz clic en **New issue**.
4. Describe el problema y los pasos para reproducirlo.
5. Adjunta una captura de pantalla si es necesario.

## Como proponer una mejora

1. Revisa los Issues existentes para evitar duplicados.
2. Crea un nuevo Issue explicando tu propuesta.
3. Indica que problema resolveria y como beneficiaria al proyecto.
4. Espera los comentarios antes de realizar cambios importantes.

## Como enviar cambios

1. Haz un fork del repositorio.
2. Clona tu fork en tu computadora.
3. Crea una rama para trabajar:

```bash
git checkout -b mejora/nueva-funcion
```

4. Realiza y prueba los cambios.
5. Guarda los cambios con un commit descriptivo.
6. Publica la rama en GitHub.
7. Abre un Pull Request explicando las modificaciones.

## Checklist antes de enviar un Pull Request

- [ ] El codigo funciona correctamente.
- [ ] Revise los archivos HTML, CSS y JavaScript modificados.
- [ ] Comprobe que el calculo del total sea correcto.
- [ ] No inclui archivos innecesarios.
- [ ] Escribi un mensaje de commit descriptivo.
- [ ] Explique los cambios en el Pull Request.
- [ ] Adjunte capturas si modifique la interfaz.

## Recomendaciones

- Utiliza nombres claros para archivos y variables.
- Evita modificar partes del proyecto que no esten relacionadas con tu mejora.
- Respeta la estructura original del repositorio.
- Comunica cualquier problema mediante GitHub Issues.
